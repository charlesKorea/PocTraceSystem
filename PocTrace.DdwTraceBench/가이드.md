# PocTrace.DdwTraceBench

SVDI 시험용 도구다. 설비 Tag 하나를 받아 DDW `tb_*`에서 그 설비의 모든 POC로부터 배관을 따라가고, 지나간 id와 table을 Excel로 남긴다. 설계 근거는 `docs/DDW_Trace_Flow_KO.md`다. PocTrace.Core와 라이선스 DLL을 쓰지 않는 독립 프로그램이다.

## 쓰는 법

1. SSMS가 붙는 FRM 서버 이름을 `서버`에 넣는다. Linked server `remote_monami`와 카탈로그 `monami`는 기본값이다. Windows 인증이 기본이다. SQL 로그인을 쓰면 암호는 저장하지 않는다.
2. `연결·스키마 확인`을 먼저 누른다. 필요한 열이 모두 있는지, Tag 속성 owner가 몇 개인지 로그에 나온다. 열 이름이 다르면 여기서 오류 메시지가 나온다. 앞 300자만 회신한다.
3. `설비 Tag`에 Tag를 넣고(기본 `rme010n03`) `추적 실행`을 누른다. Excel은 `저장 폴더`에 `ddw-trace-{Tag}-{시각}.xlsx`로 저장된다.

## 추적 규칙

- 모든 조회는 `version_sequence < 1000000000`이다. 삭제 행은 읽지 않는다.
- Tag는 `tb_attributes`에서 `attribute_nm = 'tag'`, 값 열 = Tag로 찾는다. 값 열 이름은 `attribute_val`이나 `attribute_value` 중 있는 쪽을 쓴다.
- 시작 설비의 모든 POC(`tb_pocinstances.owner_instance_id = 설비 id`)가 출발점이다. 설비 POC 하나만 따라가지 않는다.
- POC의 `connected_poc_id`가 건너편 POC다. 건너온 POC와 이미 지난 POC로는 가지 않는다.
- 건너편 POC의 `poc_template_id`가 0이면 그 소유 객체를 `tb_pipeinstances`에서 찾는다. 길이는 `length2`(mm)가 기준이고 `length1`은 예비 열에 같이 담는다. 구경은 `pipesize_id`를 `tb_pipesize.pipesize_nm`에 맞춘다.
- 0이 아니면 `tb_modelinstances`와 `tb_modeltemplates`에서 찾는다. 찾지 못하면 반대 테이블로도 한 번 찾아 본다.
- 다음에 닿으면 이름을 기록하고 그 가지를 멈춘다.
  - `modeltemplates.bim_yn = 1`인 객체.
  - 다른 설비. 설비 판정은 `model_type`, `family_key`, `bim_yn = 0` 중 하나만 만족하면 설비다. 화면의 체크박스로 켜고 끈다.
- `model_type` 51380485(connector_pipe)는 설비 판정에서 빼고 통과한다. 화면의 `통과 model_type`에서 바꾼다.
- `bim_yn = 0` 판정은 기본 꺼짐이다. 켜면 2차 설계 객체(밸브, 피팅 포함)가 거의 다 설비가 되어 첫 컴포넌트에서 추적이 멈출 수 있다. 시험 결과를 보고 켠다.
- 상태를 세분하지 않는다. 없는 연결, 없는 행은 `추적` 시트 `비고(status)` 열에 이유를 적는다.

## Excel 시트

| 시트 | 내용 |
|---|---|
| 요약 | 입력, 규칙, 한도, 스키마 메모, 설비별 배관 수와 길이 합, 종료 객체 이름 |
| Tag조회 | `tb_attributes`에서 찾은 owner. `tb_modelinstances` 유무, 세 판정 결과, 추적 여부 |
| 추적 | 출발 POC 하나당 한 행. 출발 POC id, 도착 POC id, 도착 소유 id와 소유 table, 종류, 동작, 비고 |
| 배관 | 지나간 배관. `length2`, `length1`, `pipesize_id`, `pipesize_nm`, `last_update` |
| 객체 | 컴포넌트와 종료 객체. `model_type`, `family_key`, `bim_yn`, 판정 결과를 기록해 다수 데이터로 유추할 수 있게 한다 |
| POC | 본 POC 전부. `poc_template_nm`, `equipment_yn`, `memo`, `owner_type`, `connection_order` |

Excel에는 id 전체가 들어간다. 회신에는 앞 10자와 숫자 열만 쓴다. Tag 원문도 쓰지 않는다.

## 회신

회신은 `Q=TRACE`, `분=`, 요약 시트 전체와 `추적` 시트의 비고 열(복사 가능한 만큼)이다. 오류는 로그의 앞 300자다.

## 빌드

`PocTrace.DdwTraceBench.csproj`는 .NET Framework 4.8 WinForms다. NuGet은 `EPPlus 7.2.1`, `Costura.Fody 6.0.0`이다(기존 DeletedPipeLength와 같다). Release로 빌드하면 EPPlus가 exe 안에 들어가 exe 하나로 옮길 수 있다. 서버 접속은 `System.Data.SqlClient`(프레임워크 내장)이다.
