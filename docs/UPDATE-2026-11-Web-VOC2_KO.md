# Web.exe 추가 VOC 7건 (2026-11-02)

앞선 11건(`UPDATE-2026-11-Web-VOC_KO.md`)에 이어 반영한 내용입니다.

| # | 요청 | 반영 |
|---|---|---|
| 1 | Admin이 검수 기록 삭제 (체크박스 일괄) | 기록 표에 체크박스, `선택 삭제 (n)` 버튼. `POST /api/history/delete`는 서버가 라이선스 그룹 `Admin`을 확인하고 `X-PocTrace: 1` 헤더를 요구한다. 삭제 순서: 공용 폴더 `PocTraceWebHistory\deleted.tomb`에 행 표식 추가 → 해당 사용자·월 jsonl에서 실제 삭제(파일 독점 잠금, 동시 추가는 재시도) → 이 PC 로컬 기록 삭제. 표식이 있으므로 다른 PC 로컬 사본이 있어도 조회에 다시 나오지 않는다. 공용 폴더에 닿지 않으면 아무것도 지우지 않는다. |
| 2 | 어느 화면에도 Y 드라이브 경로 미노출 | API 응답에서 `path` 제거, 오류 문구에서 경로 제거, 도움말·기록 화면 문구 수정. 서버가 모든 JSON 응답에서 공용 폴더 경로와 `Y:\...` 형태를 `[Shared]`로 가린다(`PathMask`). 로그 파일에는 남는다. |
| 3 | 검수 방식 탭을 바꾸면 진행 표시 초기화 | 탭을 바꾸면 이전 작업의 원형 진행, 상태 막대, 공용 결과 표를 지운다. 캐시 불러오기 표시와 실행 중인 작업은 유지한다. |
| 4 | 선택된 검수 방식 탭 강조 | 선택 탭을 청록-파랑 그라데이션과 흰 글씨로 표시한다. |
| 5 | 배치 Excel 불러오기 버튼은 캐시 로드 후 활성 | 다른 버튼처럼 흐리게 비활성 표시(ghost 버튼에 `:disabled` 스타일이 없었다), 클릭과 파일 선택 모두 캐시 로드 전에는 무시한다. |
| 6 | Web.exe 중복 실행 방지 | `Local\PocTrace.Web.SingleInstance` 뮤텍스(Windows 세션별). 이미 떠 있으면 팝업(한/중)을 띄우고 기존 주소를 열고 종료한다. 화면은 5초마다 heartbeat, 닫힐 때 bye를 보내며, 마지막 화면이 닫히고 12초 뒤 Web.exe가 자동 종료한다(작업 중이면 끝난 뒤). 브라우저가 비정상 종료되면 180초 뒤 종료한다. 서버가 사라지면 화면 위에 안내가 뜬다. 끄려면 `AutoExitOnBrowserClose=false`. |
| 7 | 도움말 버튼 가시성 | 보라-파랑-청록 그라데이션 알약에 `도움말` 글자와 큰 아이콘, 처음 몇 번 맥동 효과. |

## 설정 키 (Web.exe.config)

| 키 | 기본 | 뜻 |
|---|---|---|
| `AutoExitOnBrowserClose` | `true` | 브라우저 화면을 모두 닫으면 Web.exe 종료 |
| `AutoExitGraceSeconds` | `12` | 마지막 화면이 닫힌 뒤 기다리는 시간(페이지 이동 중 종료 방지) |
| `AutoExitStaleSeconds` | `180` | heartbeat가 끊긴 화면을 닫힌 것으로 보는 시간. 백그라운드 탭은 브라우저가 타이머를 늦추므로 60초보다 길게 둔다 |

## 배포

Web.exe 재빌드가 필요하다(새 `.cs` 3개). `wwwroot`에는 `assets/jcs-ui/poc-keepalive.js`가 새로 생겼다. 자세한 파일 목록은 `updates/2026-11-02_web-voc2/CHANGED-FILES.md`.
